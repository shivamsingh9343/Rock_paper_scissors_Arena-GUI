# 🪨📄✂️ Rock–Paper–Scissors Game 🎮

An interactive version of the classic **Rock–Paper–Scissors** game built using **Python** and **Streamlit**.  
The player selects Rock, Paper, or Scissors through buttons, while the computer makes its choice randomly.  
The program compares both choices, decides the winner, updates scores, and displays results with images and charts.

---
- **Stone 🪨** → Beats Scissors ✂️  
- **Paper 📄** → Beats Stone 🪨  
- **Scissors ✂️** → Beats Paper 📄
- ----

## ✨ Features
- [Interactive Interface]- With buttons and images
- [Accurate Game Logic]- For win/lose/draw calculation
- [Real‑time Score Tracking] - Using Streamlit session state
- [Rounds Management] - (Best of 3, 5, or 7)
- [Leaderboard] - To track match results
- [Replay Option] - To restart the game easily

---

## ⚙️ Tech Stack
- Python 3
- Streamlit
- Random library (built‑in)
- Pyngrok (for sharing app online via Google Colab)

📊 Workflow
--> Player selects Rock, Paper, or Scissors.
--> Computer generates a random choice.
--> Program compares both choices and decides win/lose/draw.
--> Scores are updated and displayed.
--> Game continues until chosen rounds are completed.
--> Final result is declared, with option to replay.
